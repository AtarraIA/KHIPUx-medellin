# Khipux Medellín

Sitio web estático de Khipux Medellín, publicado con GitHub Pages.

**Sitio:** https://atarraia.github.io/khipux-medellin/

## Estructura

- `index.html` — página única con las secciones *Acerca de*, *Programación* e *Inscripción*.
- `style.css` — estilos responsivos, sin dependencias ni paso de compilación.
- `.nojekyll` — desactiva el procesamiento de Jekyll; los archivos se sirven tal cual.

## Editar el contenido

Todos los textos provisionales están marcados con `[Texto pendiente]` o
`[Por definir]` dentro de `index.html`. Basta con reemplazarlos y hacer commit:
GitHub Pages vuelve a publicar automáticamente en un par de minutos.

Para la inscripción, reemplazar el enlace `mailto:` del botón *Inscribirme*
por la URL del formulario cuando esté disponible.

## Vista previa local

```sh
python3 -m http.server 8000
# abrir http://localhost:8000
```
